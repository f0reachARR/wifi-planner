# 実装計画

`docs/design.md` の設計を、次のマイルストーンの順に実装する。
順序は、後の工程が前提とするもの（ドメインの型、伝搬計算、同期基盤）を先に作り、リスクの高い壁抽出を早い段階で試す方針で決めた。

各マイルストーンの「完了条件」を満たしたら次に進む。

進み具合：M0〜M14 は完了。残っているのは、M8 の実際の図面での壁抽出の精度の評価（図面が届いてから行う）。

## M0 リポジトリの基盤

- pnpm workspaces、TypeScript の共通設定、Biome、Vitest を整える。
- `apps/web`（Vite + React + Mantine）と `apps/server`（Hono）の空のアプリを作る。
- `compose.yaml` と `Dockerfile` を置き、ボリューム上の SQLite ファイルに読み書きできることを確かめる。

完了条件：`docker compose up` で空の画面とヘルスチェック API が動く。

## M1 ドメインの中核と技術検証

ここで作るものはすべて UI なしでテストする。

- `packages/domain`：Yjs 文書の zod スキーマ、座標変換（図面座標、フロア座標、ワールド座標）、チャネル表、材質プリセット。
- `packages/propagation`：受信電力の計算式、壁区間との交差判定、アンテナ利得の加算法、AP の向きの回転、格子の計算、ヒートマップの合成（最大値、AP 数、同一チャネル干渉）。
- NFR-1 の条件（30 m × 30 m、AP 10 台、壁 300 本、0.5 m）のベンチマークを書く。
- 技術検証：opencv.js と pdfjs-dist を Node の worker thread で動かし、A3 相当の図面を 200 dpi でラスタ化して二値化、細線化、HoughLinesP まで通す。実際の図面は後日届くので、ここでは合成した図面と公開されている図面を使い、処理時間だけを確かめる。

完了条件：
- 伝搬計算の単体テストが通る（自由空間損失の既知値、壁 1 枚と 2 枚の減衰、頂点を通る線分で二重に数えないこと、アンテナ断面上の利得の一致、下向きの天井設置 AP の真下で最大利得になること）。
- ベンチマークで、1 帯域の全ラジオの計算が単一スレッドで 1 秒を下回る。
- 技術検証で、壁抽出が 60 秒以内に終わる見込みが立つ。見込みが立たなければ、ここで設計を見直す。

## M2 認証とプロジェクト管理

対象：FR-1.1、FR-1.2、FR-1.3（作成、削除）、FR-1.4

- Drizzle のスキーマとマイグレーション、初回起動時の管理者作成。
- ログイン、ログアウト、セッション、管理者画面（ユーザーの作成と無効化）。
- プロジェクト一覧、作成、削除、メンバーと権限の設定。

完了条件：閲覧権限のユーザーが、他人のプロジェクトを開けず、共有されたプロジェクトを編集できないことを API のテストで確かめる。

## M3 同期基盤

対象：FR-10.1〜10.5、FR-1.3（複製）

- Hono の WebSocket ルートから Hocuspocus の `handleConnection` に接続を渡し、`onConnect` で Cookie と権限を確かめる。閲覧者は readOnly にする。
- Database 拡張で `yjs_documents` に保存する。
- クライアントの文書アクセス層（zod で検証した読み取り、トランザクションでの書き込み、`Y.UndoManager`、y-indexeddb）。
- awareness によるカーソルと選択の表示。
- プロジェクトの複製。

完了条件：Playwright で 2 つのブラウザを開き、片方の変更がもう片方に反映されること、切断中の変更が再接続後に統合されること、閲覧者の書き込みと、Cookie もトークンも持たない接続がサーバで拒否されることを確かめる。

## M4 図面の取り込みとスケール

対象：FR-2.1〜2.5、FR-3.1

- ファイルのアップロード（blob、`project_files`、権限つきの取得 API）。
- PDF のページ選択とラスタ化、画像の取り込み。
- 2D エディタの土台（Konva のステージ、パンとズーム、図面の表示、回転とトリミング）。
- 2 点を指定するスケール校正、未校正の表示。
- フロアの追加、並べ替え、標高と階高の設定。

完了条件：PDF から図面を作り、スケールを校正し、フロアを複数持つプロジェクトを作れる。

## M5 壁の編集と材質

対象：FR-4.4〜4.9

- 材質の管理画面とプリセット。
- 壁の描画（端点と直交方向へのスナップ）、移動、分割、結合、削除。
- 選択（クリックの追加選択、矩形、投げ縄、同じ材質の一括選択）と、選択した壁の一括の材質変更と削除。
- ドアと窓の区間の追加と編集。
- 壁を材質の色で描く。

完了条件：分割と結合で開口部の位置が保たれることを単体テストで確かめ、一括操作が一度の undo で戻ることを確かめる。

## M6 AP モデルと AP の配置

対象：FR-5.1〜5.4、FR-6.1〜6.5

- AP モデルのライブラリ画面、CSV と JSON からのアンテナパターンの取り込み、極座標グラフ。
- AP の配置、移動、複製、削除。配置時に AP モデルをプロジェクトに写す。
- AP の設置高さ、方位角、チルト、設置方法の設定。
- ラジオごとの有効と無効、チャネル、チャネル幅、送信出力の設定（IEEE 802.11 の範囲から選べ、国内で使えないものには印を付ける）。
- AP の一覧表と、表からの一括変更。

完了条件：AP を配置してラジオを設定でき、国内で使えないチャネルを選ぶと注意が出る。

## M7 伝搬計算と可視化

対象：FR-7.1〜7.5、FR-8.1〜8.8、NFR-1

- Worker プール（Comlink）とラジオ単位のキャッシュ、デバウンス、古い計算の破棄。
- 帯域の切り替え、対象 AP の絞り込み、凡例と閾値の設定。
- ヒートマップ（最大受信電力、AP 数、同一チャネル干渉）の描画。
- カーソル位置での AP ごとの受信電力の一覧。

完了条件：NFR-1 の条件のプロジェクトで、AP を動かしてからヒートマップが更新されるまでが 1 秒程度に収まり、その間もパンとズームが止まらない。

## M8 壁の自動抽出

対象：FR-4.1〜4.3、NFR-2

- `packages/wall-extraction` に M1 の技術検証を本実装として移す。
- 細線をたどって折れ線にする方式を試し、Hough 変換と精度を比べる（設計書 9.3 節）。
- 端点どうしをつないで折れ線にまとめる。
- 抽出ジョブの API（作成、状態の取得、結果の取得）と Piscina での実行、60 秒の上限。
- 感度の調整画面、候補の表示、一括と個別の採用と却下。

完了条件：提供された図面で抽出が 60 秒以内に終わり、採用した候補が既定の材質の壁になる。

## M9 複数フロアの重ね表示と疑似 3D ビュー

対象：FR-3.2〜3.6

- 基準点 2 点によるフロア間の位置合わせと、スケールの食い違いの警告。
- 他のフロアの図面と要素の半透明の重ね表示。
- 疑似 3D ビュー（図面、高さを持つ壁、AP、各フロアのヒートマップ）。

完了条件：3 フロアのプロジェクトを 3D で表示し、位置合わせの結果どおりに積み重なる。

## M10 現場写真

対象：FR-9.1〜9.4

- 写真のアップロード、縮小画像の作成、EXIF の撮影日時の取得と位置情報の除去。
- 図面上のピン、撮影方向とメモの設定、拡大表示。

完了条件：一つのピンに複数枚の写真を付け、撮影日時が表示される。

## M11 エクスポート、インポート、運用

対象：FR-1.5、NFR-5、NFR-6

- ZIP 形式のエクスポートとインポート、スキーマのマイグレーションの仕組み。
- バックアップと復元のスクリプトと手順書。
- 使われなくなった blob の削除。
- E2E テストの整備（ログインから、図面の取り込み、壁の描画、AP の配置、ヒートマップの表示まで）。

完了条件：エクスポートしたプロジェクトを別の環境にインポートして同じヒートマップが得られ、バックアップから復元できる。

## M12 壁の高さとフロアをまたぐ伝搬計算

対象：FR-3.1、FR-3.5、FR-3.8、FR-4.6、FR-4.8、FR-4.10、FR-4.11、FR-7.1、FR-7.2、FR-7.5〜7.8、FR-8.3、FR-8.7、FR-8.8、NFR-1

段階 1（壁の高さ）

- スキーマの版 3（壁の高さ、床スラブの材質、`crossFloorRange`）と、マイグレーション、床スラブのプリセット。
- 壁区間に絶対の高さの範囲を持たせ、交点の高さで減衰を加えるかを決める（設計書 6.1.1 節）。開口部の高さも使う。
- 壁の高さの入力と一括変更、3D ビューでの壁と開口部の高さの描画。
- 高さの範囲が重なる壁の警告（設計書 4.1.1 節）。他のフロアの壁との組は段階 2 で足す。

段階 2（フロアをまたぐ計算）

- ワールド座標での計算、アンテナの基底へのフロアの回転の適用、床スラブと吹き抜けの判定（設計書 6.1.2 節）。
- 計算に含めるフロアの決定と、含めないフロアの扱い（設計書 6.4 節）。
- Worker に送る文書の範囲、組ごとのキャッシュと、組に効くフロアだけを見た環境のキー（設計書 6.2 節）。
- 高さによる絞り込みを入れてベンチマークを取り、足りなければ一様格子を入れる（設計書 6.3 節）。3 フロアで約 290 ms だったので、一様格子は入れていない。

段階 3（画面）

- フロアの設定に床スラブの材質、伝搬計算の設定に対象とするフロアの範囲を足す。
- AP の絞り込みとカーソル位置の一覧に他のフロアの AP を出す。
- 計算に含めなかったフロアの知らせ。

完了条件：

- 壁の高さを指定しない 1 フロアのプロジェクトで、版 2 と同じヒートマップが得られる。
- 3 フロアのプロジェクトで、上下のフロアの AP が床スラブの減衰を受けて届き、吹き抜けの範囲では減衰を受けずに届く。
- NFR-1 の条件のフロアを 3 つ重ね、全フロアを対象にしても、編集中のフロアの更新が 1 秒程度に収まる。

## M13 縦の断面のヒートマップ

対象：FR-3.9

- 点ごとの高さで受信電力を求める関数と、断面の格子（設計書 6.5 節）。
- 点の属するフロアによる AP の絞り込みと、計算に含めないフロアの点の扱い。
- Worker への断面の計算の依頼と、断面ごとのキャッシュ。
- 3D ビューでの断面の描画と、向きと位置の操作。

完了条件：3 フロアのプロジェクトで、1F の AP の電波が床スラブで弱まり、吹き抜けの範囲では弱まらずに上のフロアへ届く様子が断面で見え、断面を動かすと 1 秒程度で追従する。

## M14 3D ビューでの AP と断面の操作

対象：FR-3.6、FR-3.9

- 設置方法、方位角、チルトに従って向けた AP の箱の表示と、クリックでの AP と断面の選択。
- AP の位置、高さ、方位角、チルトを変えるつまみと、文書への書き込み（設計書 13 章）。
- 断面を断面に垂直な向きに動かし、鉛直な軸のまわりに回すつまみ。

完了条件：3D ビューで AP をつまみで動かして回すと 2D ビューの位置、方位角、チルトに反映され、1 回の元に戻すで戻る。断面をつまみで動かすと、スライダーと断面のヒートマップが追従する。
